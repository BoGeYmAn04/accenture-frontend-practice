# Exercise 04 — Center It

**Difficulty:** Easy · **Track:** Foundations · **Focus:** Flexbox, CSS Grid, absolute positioning

## Scenario
Three boxes each contain a dot. Center the dot inside each box using **three
different techniques** — this is one of the most common CSS interview tasks.

## Requirements
1. `#stage-flex`: center `.dot` using **flexbox**.
2. `#stage-grid`: center `.dot` using **CSS Grid**.
3. `#stage-abs`: center `.dot` using **absolute positioning** (`position` + offsets).

The dot must be centered **horizontally and vertically** in all three cases.

## Tasks
- **Task 1–3 — Update `style.css` only.** The HTML must not change.
