# Exercise 03 — Click Counter

**Difficulty:** Easy · **Track:** Foundations · **Focus:** DOM selection, events, `textContent`

## Scenario
Build the JavaScript for a simple click counter. The HTML and CSS are already in
place; you only need to make the buttons work.

## Requirements
1. The counter starts at `0` (already shown in the HTML).
2. Clicking **Click me** (`#increment`) increases the count by 1 and updates `#count`.
3. Clicking **Reset** (`#reset`) sets the count back to `0` and updates `#count`.
4. Style `.secondary` as a muted/outline variant so it is visually distinct.

## Tasks
- **Task 1 — Modify `index.html`:** (already complete — read it and note the ids).
- **Task 2 — Update `style.css`:** style the `.secondary` button.
- **Task 3 — Update `script.js`:** implement the counter logic.
