# Exercise 02 — Style the Profile Card

**Difficulty:** Easy · **Track:** Foundations · **Focus:** CSS selectors, box model, typography

## Scenario
The HTML for a profile card is complete. It is currently **unstyled**. Write the
CSS so it looks like a polished profile card.

## Requirements
1. `.profile-card`: white background, rounded corners (≥ 12px), padding (≥ 16px),
   a soft `box-shadow`, centered text, sensible width.
2. `.avatar`: a circle — equal width/height (≥ 64px), `border-radius: 50%`,
   colored background, bold centered text.
3. `.name`: bold (`font-weight` ≥ 600) with a larger font-size.
4. `.role`: a muted/secondary color.
5. `.tags`: no bullet points, laid out in a row. `.tag`: padding, background
   color, rounded corners, smaller font-size.
6. `.follow-btn`: colored background, white text, padding, rounded corners,
   `cursor: pointer`.

## Tasks
- **Task 1–6 — Update `style.css` only.** The HTML must not change.
