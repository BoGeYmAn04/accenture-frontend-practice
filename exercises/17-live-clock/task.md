# Exercise 17 — Live Digital Clock

**Difficulty:** Easy–Medium · **Track:** Advanced · **Focus:** `Date`, `setInterval`, zero-padding

## Scenario
Build a digital clock that shows the current local time as `HH:MM:SS` and
updates every second.

## Requirements
1. `#clock` shows the time in `HH:MM:SS` format, zero-padded.
2. It updates automatically every second.
3. It reflects the real current time.

## Tasks
- **Task 1 — Update `style.css`:** style the clock.
- **Task 2 — Update `script.js`:** build the clock.

## How to check
```bash
npm test -- exercises/17-live-clock
npm run test:solutions -- exercises/17-live-clock
```
